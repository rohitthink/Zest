Zest

Drop a file, pick a format, done. Or paste a link and save it.
Images · audio · video · documents YouTube · Instagram · Facebook · Pinterest Free · works offline · no account

Zest is a tiny converter that lives in your menu bar (top-right of the screen, next to the clock). Drag any file onto it and an orange slice pops up — each slice is a format you can turn the file into. Pick one and the new file appears right next to the original. It can also save videos, audio and images from links. Everything happens on your Mac; nothing is uploaded.

1 · Install it (2 minutes)

  1. Open the Zest disk image you received, and drag Zest onto the Applications folder next to it.
  2. Open Zest from Applications. The first time, macOS will stop it with a message like “Apple could not verify ‘Zest’ is free of malware”. That's expected — Zest is a friend-made app, not from the App Store, so it isn't registered with Apple. Click Done.
  3. Open System Settings → Privacy & Security, scroll down to the Security part, and next to “‘Zest’ was blocked to protect your Mac” click Open Anyway. Confirm with Open Anyway and your password or Touch ID. On macOS 13 or 14 you can instead right-click Zest in Applications and choose Open.
  4. That's it — macOS remembers your choice. Look for the orange slice in your menu bar.

Needs macOS 13 Ventura or newer. Works on both Apple silicon (M-series) and Intel Macs. Comfortable with Terminal? Instead of steps 2–3 you can run xattr -dr com.apple.quarantine /Applications/Zest.app once.

2 · Unlock audio, video and link downloads (optional, one time)

Photos and documents work straight away. A few free tools add the rest:

  1. Install Homebrew (the standard free installer for Mac tools): go to brew.sh, copy the one command shown at the top, paste it into Terminal (in Applications → Utilities) and press Return.
  2. Then paste this and press Return:
    brew install ffmpeg yt-dlp webp
    For Excel/PowerPoint files also: brew install --cask libreoffice
  3. In Zest, open Settings → Advanced: each tool should now say Found.

Tip: run brew upgrade yt-dlp now and then — sites change and yt-dlp keeps up.

3 · Convert a file

  1. Drag a file (or several) onto the Zest drop zone. If it's hidden, click the menu-bar slice → Drop zone, or just drop the file onto the menu-bar slice itself.
  2. While you're still dragging, the orange slice opens. Each segment is a format. Let go over a segment to convert — or drop anywhere and then click one. Number keys 1–9 work too.
  3. The new file appears next to the original (change this in Settings). Click Show in Finder to see it.

Good to know

Strip (on photos) removes the location and camera details without changing a single pixel — handy before sharing. It saves a copy named like photo-clean.jpg.

Lots of files at once? Drop them together; the slice offers formats they can all become. Files already in that format are left alone.

From Finder: right-click a file → Open With → Zest.

Zest never overwrites anything: if the name is taken you get photo (2).jpg.

4 · Save from a link

  1. Copy a link from YouTube, Instagram, Facebook, Pinterest (and many other sites).
  2. Click the menu-bar slice and paste it into “Paste a link to download…” — or open the drop zone and press ⌘V, or drag the link from your browser onto the drop zone.
  3. Zest reads the link for a second, then the slice shows only the options that link really has. Pick one.
  4. The file lands in your Downloads folder, named after the video.
SliceWhat you get
MP4 4K (Best)Highest quality video with sound. Above 1080p, YouTube uses a newer format (AV1/VP9): plays in QuickTime on M3-or-newer Macs; otherwise use the free VLC or IINA player.
MP4 1080p (Plays everywhere)H.264 video — plays on every phone, TV and app. Shown when it differs from Best.
M4AJust the audio, exactly as the site has it — the best audio quality available.
MP3Audio as MP3 320 kbps, for older players and car stereos.
WAVUncompressed audio for editing apps.
ImageThe full-size picture from a photo post (e.g. Pinterest).

Honest note: these sites only keep compressed audio (about 128–160 kbps). MP3 320 and WAV can't add back quality the site never had — they're for compatibility and editing. M4A is the original.

Private posts or “please sign in”

Some posts (Instagram stories, some reels, members-only videos) need you to be signed in. Go to Settings → Output → Use sign-in from and pick the browser you're signed in with. Safari needs Zest to have Full Disk Access (System Settings → Privacy & Security); Chrome, Brave and Edge will ask for Keychain access once. Leave it Off if you don't need it.

Only save what you have the right to — your own posts, Creative-Commons videos, or with permission. Each site's terms apply.

5 · The menu and Settings

Click the orange slice in the menu bar for the Zest menu: convert a file, paste a link, your recently made files (click one to show it in Finder), the drop zone, Settings and Quit. Right-click it for a plain menu, including Download Link from Clipboard.

Settings worth knowing

General: where files go — next to the original (default), your Downloads folder, or ask every time; quality (smaller files ↔ sharper results); removing location & camera info (on by default); launch at login.

Output: shrink big photos and videos to a longest side (4096 / 2048 / 1080 px), show in Finder or play a sound when done, and browser sign-in for links.

Advanced: shows which helper tools Zest found (see section 2).

6 · If something's off

“Zest can't be opened” / “not verified”Do step 1.3 above (Privacy & Security → Open Anyway). If it says “damaged”, run the Terminal line from section 1.
I don't see Zest anywhereIt has no Dock icon — look for the orange slice in the menu bar. Opening the app again shows the drop zone.
Videos or audio offer no formatsInstall ffmpeg (section 2), then check Settings → Advanced.
“Downloading links needs yt-dlp”brew install yt-dlp ffmpeg
A site “wants you signed in”Settings → Output → Use sign-in from (section 4).
A download stopped workingSites change often: brew upgrade yt-dlp, then try again.
Where did my file go?Next to the original by default; links go to Downloads. The menu's “Recently squeezed” list shows them — click to reveal.
UninstallQuit from the menu, then drag Zest from Applications to the Trash.
